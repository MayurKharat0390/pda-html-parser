# Pushdown Automata & CFG in HTML Parsing

An interactive visualization tool demonstrating how **Pushdown Automata (PDA)** and **Context-Free Grammars (CFG)** parse structured markup like HTML.

## 🚀 Live Demo
Access the live application at:
**[https://mayurkharat0390.github.io/pda-html-parser/](https://mayurkharat0390.github.io/pda-html-parser/)**

## ✨ Features
- **Interactive PDA Simulator**: Visualizes the internal state and pushdown stack in real-time as HTML tokens are parsed.
- **Context-Free Grammar (CFG) Rule Matching**: Displays matched production rules and grammar derivation steps.
- **Step-by-Step & Auto-Play Modes**: Step through parsing line by line or play continuously at configurable speeds.
- **Error Detection & Reporting**: Highlights syntax errors, unclosed tags, and mismatched nested tags with helpful diagnostics.
- **Modern Responsive UI**: Built with dark/light themes, sleek animations, and responsive controls.

## 🛠️ Local Usage
Simply open `index.html` in any modern web browser:
```bash
# Windows PowerShell
Start-Process index.html
```
